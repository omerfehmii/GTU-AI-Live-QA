University candidates, students, and live broadcast audiences often ask institution-specific questions whose answers are distributed across official web pages, regulations, guides, and PDF documents. Generic chatbots can respond fluently, but they may fail to ground answers in the latest institutional context and may not fit the rhythm of a live question-answer setting. This graduation project presents an AI/RAG-based live question-answer system for Gebze Technical University (GTU). The system collects official GTU web pages and PDF documents, archives them locally, splits them into searchable chunks, retrieves relevant context for each user question, and generates concise Turkish answers with a large language model. In addition to a standard web dashboard, the project includes an admin console, YouTube live chat integration, a worker process for queued questions, text-to-speech generation, and a browser-based avatar stage for live presentation.

The backend is implemented with FastAPI, SQLAlchemy, PostgreSQL with pgvector for production vector search, and a SQLite-compatible mode for local tests. The frontend is implemented with Next.js, React, Three.js, and a live-state polling model. Retrieval combines semantic embeddings with keyword, title, URL, document-type, and intent-based scoring so that official GTU documents remain the main evidence source. A 12-question evaluation set was used to measure retrieval and answer behavior. The latest recorded run achieved a 100\% source hit rate, an 83.33\% top-1 source hit rate, a 91.67\% answer keyword hit rate, no fallback answers, and a median latency of 6.58 seconds. These results show that the system is suitable for a controlled live demo while also identifying top-1 ranking precision and latency as the main areas for improvement.
